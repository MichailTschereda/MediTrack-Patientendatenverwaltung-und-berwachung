# Online-Abstimmungssystem für Bürgerbefragungen

Eine sichere PlaWorm für Online-Abstimmungen,
bei der Bürger über städtische Entscheidungen oder Projekte abs<mmen können.


# Funktionale Anforderungen:
- Nutzerregistrierung und Authen.fizierung: Registrierung für Bürger mit gesicherter Authentifizierung (z.
  B. durch E-Mail-Bestättigung oder 2-Faktor-Authentifizierung).
- Abstimmungsübersicht: Bürger können sich eine Liste der aktuellen Abstimmungen ansehen, inklusive
  Beschreibung und Frist.
- Abstimmungsmechanismus: Bürger können an den Abstimmungen teilnehmen und ihre Stimme abgeben
  (einfacher Voting-Mechanismus).
- Ergebnisübersicht: Nach Abschluss der Abstimmung können Bürger die Ergebnisse einsehen.
- Abstimmungssicherheit: Sicherstellen, dass jeder Bürger nur 1x abgestimmt (z. B. durch eindeutige Kennung)
