# Online-Abstimmungssystem für Bürgerbefragungen
Eine sichere Platform für Online-Abstimmungen,
bei der Bürger über städtische Entscheidungen oder Projekte abstimmen können.

# Funktionale Anforderungen:
- Abstimmungsübersicht: Bürger können sich eine Liste der aktuellen Abstimmungen ansehen, inklusive
  Beschreibung und Frist.
- Abstimmungsmechanismus: Bürger können an den Abstimmungen teilnehmen und ihre Stimme abgeben
  (einfacher Voting-Mechanismus).
- Ergebnisübersicht: Nach Abschluss der Abstimmung können Bürger die Ergebnisse einsehen.
- Abstimmungssicherheit: Sicherstellen, dass jeder Bürger nur 1x abgestimmt (z. B. durch eindeutige Kennung)
- Nutzerregistrierung und Authen.fizierung: Registrierung für Bürger mit gesicherter Authentifizierung (z.
  B. durch E-Mail-Bestättigung oder 2-Faktor-Authentifizierung).

# Git

## Was ist Git und warum sollte es verwendet werden?
Git ist ein Versionskontrollsystem, das jede Änderung an Dateien oder Quellcode nachverfolgt, speichert und somit die Zusammenarbeit an Projekten erleichtert.

## Grundlegende Git-Befehle
- git init: Erstellt ein neues, leeres Git-Repository in deinem aktuellen Ordner.
- Git add: Fügt geänderte Dateien zur Staging-Area hinzu, um sie für den nächsten Commit vorzubereiten.
- Git commit: Speichert die vorbereiteten Änderungen dauerhaft als neuen Snapshot (mit einer kurzen Beschreibung) in der lokalen Historie
- Git push: Lädt deine lokalen Commits hoch auf das entfernte Server-Repository
